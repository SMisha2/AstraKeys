## 📖 О программе

**AstraKeys** – это приложение на **PyQt6**, которое эмулирует нажатия клавиш для игры на пианино в Roblox. Оно позволяет:

- Воспроизводить заранее подготовленные песни (текстовый формат с нотами и аккордами).
- Записывать и воспроизводить живую игру с точностью до миллисекунды.
- Управлять плейлистом, настраивать задержки, педали и внешний вид.
- Работать в трёх языках: русском, английском и украинском.

## ✨ Особенности

| Функция | Описание |
|---------|----------|
| 🎼 **Воспроизведение песен** | Поддерживает ноты и аккорды `[ ... ]` с возможностью пропуска и перемотки. |
| 🎚️ **Два режима игры** | *Ровный* (все ноты одновременно) и *С задержками* (случайные задержки для каждой ноты). |
| ⏺️ **Запись нажатий** | Сохраняет все нажатия и отпускания в форматы **JSON** и **MIDI**. |
| ▶️ **Воспроизведение записей** | Точное повторение с поддержкой **паузы и возобновления**. |
| 📂 **Управление плейлистом** | Добавление, удаление, переименование, перетаскивание, импорт/экспорт в JSON. |
| 🖥️ **Прозрачный оверлей** | Отображение текущих нот с подсветкой, прогресс-баром и настройкой прозрачности. |
| 🦶 **Настраиваемые педали** | Возможность назначить любые клавиши как педали (по умолчанию `-`, `=`, `[`, `]`). |
| 🌍 **Мультиязычность** | Интерфейс на русском, английском и украинском языках. |
| 🚀 **Автообновление** | Проверка новых версий на GitHub и автоматическая замена исполняемого файла. |
| 📋 **Просмотр логов** | Встроенное окно с последними записями лога. |

## 🛠️ Установка и запуск

### Требования

- **Python 3.8** или выше
- Установленные зависимости:

```bash
pip install PyQt6 pynput requests midiutil pywin32
```

⚠️ Для работы с Roblox на Windows рекомендуется запускать программу от имени администратора.
Запуск из исходников
```bash
python AstraKeys.py
```
Сборка исполняемого файла (опционально)
```bash
pip install pyinstaller
pyinstaller --onefile --windowed --icon=icon.ico AstraKeys.py
```

🎮 Использование
Главное окно
Плейлист – список песен. Можно перетаскивать, редактировать двойным кликом.

Панель управления – кнопки Start/Pause (F1), Запись (F12), Воспр. запись, След. песня, переключение режима.

Настройки:

Случайные задержки (мин/макс) – для режима 2.

Задержка запуска – общая пауза перед каждой нотой (в мс).

Язык – выбор языка интерфейса.

Настройка педалей – открывает диалог добавления/удаления клавиш-педалей.

Добавление песни
Вставьте текст песни в поле ввода (ноты и аккорды в квадратных скобках, например [eT]).

Нажмите Добавить и введите название.

Песня появится в плейлисте.

Запись игры
Нажмите F12 (или кнопку ⏺ Запись).

Играйте на клавиатуре – все нажатия и отпускания запоминаются.

Нажмите F12 снова – появится окно для ввода названия записи.

Файлы (JSON и MIDI) сохраняются в папку recordings.

Воспроизведение записи
Нажмите ▶ Воспр. запись.

В открывшемся диалоге выберите запись из списка (можно отметить избранное, переименовать, удалить).

Нажмите OK – запись начнётся.

Во время воспроизведения доступны кнопки Пауза и Остановить.

Оверлей
Перетаскивается за верхнюю панель.

Кнопка 📌 – закрепление поверх всех окон.

Кнопка 👁️ – настройка прозрачности (от 1% до 100%).

Правая кнопка мыши – настройка размера шрифта и количества строк.

Импорт / экспорт плейлиста
Экспорт – сохраняет текущий плейлист в JSON (по умолчанию в папку Загрузки).

Импорт – добавляет песни из JSON-файла к текущему списку.

Обновление клиента
Нажмите Обновить клиент – программа проверит GitHub и при наличии новой версии скачает и заменит файл.

⌨️ Горячие клавиши
Клавиша	Действие
F1	Старт / Пауза воспроизведения песни
F2	Перезапуск текущей песни
F3	Перемотка вперёд на 25 нот
F4	Перемотка назад на 25 нот
F6	Заморозка текущей ноты (повторно – отключить)
F7	Переключение режима (1 ↔ 2)
F8	Следующая песня в плейлисте
F9	Стоп / Пауза воспроизведения записи
F12	Начать / остановить запись
⚙️ Файлы конфигурации
Программа создаёт следующие файлы (все в папке с исполняемым файлом):

Файл	Назначение
app_settings.json	Язык, режим, задержки
playlist.json	Список песен
recordings_index.json	База данных записей
overlay_settings.json	Настройки оверлея (прозрачность, шрифт, строки)
pedal_settings.json	Список клавиш-педалей
window_state.json	Геометрия главного окна
astrakeys.log	Лог-файл приложения
crash.log	Стек ошибок (при сбоях)
🐛 Сообщения об ошибках
В случае сбоя программа сохраняет стек ошибки в crash.log.
Основной лог пишется в astrakeys.log – его можно просмотреть через кнопку Показать лог в интерфейсе.
